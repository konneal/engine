# F7 — Semantic edition diffs + temporal jurisdiction

**Powering objects:** editions/2017/*.prl — a FULL prior-edition model
package (not a separate PDF) — plus edition lifecycle (status,
supersedes, validity.from).

**The win, beyond L6:** diffs become SEMANTIC, not textual:
*"what changed in creep between 2017 and 2021?"* → diff the two MODELS:
the constraint set (new OCL checks), attribute definitions (added
fields, moved scopes), test sequences (reordered steps), tier tables
(changed breakpoints) — each delta with both editions' clause anchors.
Text diffs of two PDFs produce noise; model diffs produce CHANGE RECORDS.

**Temporal jurisdiction:** validity windows answer retro-questions —
*"an evaluation performed 2019-11: which edition governed it, and is
its verdict still valid today?"* → 2017 governs; superseded-by chain
says whether re-evaluation is required. Legal-metrology gold: the
corpus knows TIME, not just content.
