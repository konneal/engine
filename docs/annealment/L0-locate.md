# L0 — LOCATE (primitives P1–P2)

**Definition:** find WHERE the corpus addresses a topic; return the clause
anchor. No value, no synthesis — presence and position only.

**Why it's the floor:** it isolates retrieval from understanding. A lane
failing L0 is mis-built (chunking/embedding bug), not "less annealed" —
the floor validates the harness before the ladder means anything.

**Example** — *"Where does R 60 address creep?"*
Witness: citation anchor ∈ {R 60-1 §3.x (definition), R 60-2 §2.11.x
(test)} — either is a pass; the anchor must EXIST and be normative.
Lane expectations: A/B/C/D/E all pass (sanity). Primmel additionally
binds the term to its `behaviors: [creep]` entry with stimulus/response
and the `load-cell` entity — same anchor, richer provenance.

**Harness notes:** 6 questions spanning definition-anchors, test-anchors
and annex-anchors; paraphrases use colloquial synonyms ("time drift under
load") so lexical lanes can't win by string match alone.
