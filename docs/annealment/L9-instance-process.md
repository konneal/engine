# L9 — INSTANCE & PROCESS (P10)

**Definition:** answers about PARTICULAR things and ORDERED activities —
knowledge that exists only where the model records instances and
sequences.

**Sub-probes:**
- **a) process order & consequence** — *"what is contaminated if creep
  runs before MDLO on the same sample?"* → test_sequences.yaml
  `mdlo-creep-dr`: MDLO is the BASELINE (order 1), creep FOLLOWS (order
  2), DR reads against creep's D_max; witness: the ordering verdict +
  "contaminates the baseline". The rationale is ENCODED as sequence
  semantics — prose lanes only pass if the corpus happens to print it
  (containment-checked; the printed form exists in R 60-2 — so the
  probe asks the COUNTERFACTUAL form: "may I run them in my own
  order?" → D answers from the model rule).
- **b) instance-grounded fact** — a sample instrument profile →
  "what is ITS E_R budget?" — the model evaluates at the instance.
- **c) execution form** — *"where is E_R recorded in the test report?"*
  → execution/test-report.yaml + subforms (R 60-3 2.1.3).

Lane expectations: **D only.** The deepest binding: the corpus doesn't
describe the general — it RECORDED the particular and the ORDER.
