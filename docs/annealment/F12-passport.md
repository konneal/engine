# F12 — The machine passport (r60-to-dpp.prm)

**Powering objects:** evaluation/r60-to-dpp.prm — a composed artifact
that projects the model toward a Digital Product Passport — plus
certificate-template.yaml and the verdict chain.

**The win:** answers become EXPORTS. A conformity answer in the D lane
can terminate in a structured `.prm`/DPP payload — the clause chain,
the verdicts, the parameters — that downstream systems (customs,
procurement, market surveillance) consume as DATA. The Q&A service
stops being the end of the pipeline and becomes an oracle other
machines query.

**Answer-contract form:** the ultimate block type — alongside table,
formula, verdict — a `passport` block: machine-readable, signed by
provenance, rendered in the UI as a downloadable artifact. Prose is for
humans; the passport is for systems.
