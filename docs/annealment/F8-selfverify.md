# F8 — Self-verification as a query (meta-grounding)

**Powering objects:** the model-linker rule set (quantity-coherence,
requirement-binding-targets) and the allowlist ledger whose history
reads "burned to empty — every formerly allowlisted site was fixed at
the data layer": the model is MACHINE-CHECKED consistent.

**The win:** for model-grounded claims, execution replaces the judge.
When the D lane answers "the class C limit factor is 0.35", it can
VERIFY that claim against the model (the value is read from the typed
table, not generated) — and the user can ask *"is this corpus
internally consistent?"* and receive the linker verdict. The
faithfulness judge (an LLM scoring prose) remains for synthesis; for
model-grounded facts, the check is arithmetic.

**Why it matters:** it closes the trust loop — the same mechanism that
answers also proves. The strongest possible grounding story for the
paper: not "the model was cited" but "the model was EXECUTED, and the
execution is checkable".
